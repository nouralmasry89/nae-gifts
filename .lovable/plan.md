# خطة موقع N.A.E Gifts Store

موقع عرض (Catalog) بسيط باللغة العربية، اتجاه RTL، يعرض فئات الهدايا المخصصة. الطلبات تتم عبر واتساب — بدون سلة شراء أو دفع إلكتروني (يمكن إضافتها لاحقاً عند الحاجة).

## الهوية البصرية
- الألوان مستوحاة من اللوغو: أسود (#0d0d0d) كخلفية رئيسية، أحمر (#e30613) كلون مميّز، أبيض للنصوص.
- خطوط عربية أنيقة: Tajawal للعناوين والنصوص.
- اتجاه الصفحة `dir="rtl"` و `lang="ar"`.

## معالجة اللوغو
- نسخ الصورة المرفقة إلى `src/assets/logo-nae.jpg` واستخدامها كما هي في الهيدر والفوتر و favicon (الخلفية السوداء للوغو تنسجم مع ثيم الموقع، لذا لا حاجة لتفريغ الخلفية تقنياً — وإن أردت تفريغها لاحقاً نقوم بذلك).

## بنية الصفحات (Routes)
- `/` — الصفحة الرئيسية: هيرو باللوغو + شعار "هدايا فريدة ومخصصة" + زر "اطلب عبر واتساب" + شبكة الفئات التسع + قسم "من نحن" مختصر + معلومات التواصل.
- `/category/$slug` — صفحة فئة: تعرض اسم الفئة، وصف قصير، شبكة صور توضيحية (placeholders قابلة للاستبدال لاحقاً بصور حقيقية)، وزر "اطلب هذا التصميم عبر واتساب" يفتح محادثة مع رسالة جاهزة تذكر اسم الفئة.
- `/contact` — صفحة التواصل: الواتساب، فيسبوك، انستغرام، نموذج بسيط يحوّل إلى رسالة واتساب.

## الفئات التسع
ستاندات محابس، صناديق مهر وهدايا، باقات ورد صناعي، عيد الأم، عيد المعلم، أعياد الميلاد، رمضان والأعياد، تخرج، مولود جديد. كل فئة لها slug وأيقونة ولون مميّز وصورة غلاف يتم توليدها.

## التواصل
- واتساب: رابط `https://wa.me/963982244635` (إزالة الـ 00 لأن wa.me يستخدم الصيغة الدولية بدون +).
- فيسبوك: `https://www.facebook.com/N.A.E.2020`
- انستغرام: `https://www.instagram.com/n.a.e.gifts`
- زر واتساب عائم (Floating) في كل الصفحات على الزاوية اليسرى السفلية.
- روابط السوشيال في الهيدر والفوتر.

## المكونات الرئيسية
- `Header` — لوغو + روابط (الرئيسية، الفئات، تواصل) + أيقونات سوشيال.
- `Footer` — معلومات المتجر + روابط الفئات + التواصل.
- `CategoryCard` — بطاقة فئة بصورة وعنوان.
- `WhatsAppFloat` — زر عائم.
- `categories.ts` — مصدر بيانات واحد للفئات يستخدمه الهيدر والصفحة الرئيسية وصفحات الفئات.

## تفاصيل تقنية
- TanStack Start بالبنية الحالية (`src/routes/`).
- إضافة خط Tajawal عبر Google Fonts في `__root.tsx`.
- تحديث `styles.css` بألوان الثيم (أسود/أحمر) ومتغيرات `--primary` للأحمر.
- توليد 9 صور غلاف للفئات بصور هدايا مناسبة لكل فئة باستخدام `imagegen` وحفظها في `src/assets/categories/`.
- meta tags عربية وSEO لكل صفحة (title, description, og).

## خارج النطاق حالياً
- لا توجد سلة شراء أو نظام دفع أو لوحة تحكم.
- لا قاعدة بيانات — المحتوى ثابت في الكود (يسهّل تعديله لاحقاً).
- صور المنتجات داخل كل فئة تكون placeholders قابلة للاستبدال — أرسل لي صور منتجاتك الحقيقية لاحقاً وأضيفها.
