## الخطة

### 1. تحديث بيانات المنتجات `src/lib/products.ts`
إضافة حقول جديدة لكل منتج:
- `price: number` (السعر)
- `currency: string` ("ل.س" افتراضياً، قابل للتعديل)
- `description: string` (وصف قصير مخصص)

ملاحظة: بانتظار قائمة الأسعار والأوصاف منك. سأضع قيماً مؤقتة ثم نعدّلها فور إرسالك للقائمة.

### 2. صفحة تفاصيل المنتج (جديدة)
ملف جديد: `src/routes/product.$id.tsx` — مسار `/product/{id}`
المحتوى:
- زر رجوع للقسم
- صورة كبيرة للمنتج (aspect-square، قابلة للتكبير على الديسكتوب)
- اسم المنتج (H1)
- السعر بشكل بارز (بلون أحمر العلامة التجارية)
- الوصف القصير
- **خيارات قبل الطلب**:
  - حقل "تخصيص الاسم / اللون" (input)
  - حقل "ملاحظات إضافية" (textarea)
- زر "اطلب عبر واتساب" يبني الرسالة تلقائياً وتشمل:
  ```
  مرحباً، أود طلب:
  • المنتج: {الاسم} ({id})
  • السعر: {price} {currency}
  • التخصيص: {customization}
  • ملاحظات: {notes}
  ```
- meta tags ديناميكية (title, description, og:image من صورة المنتج)
- `notFoundComponent` و `errorComponent`

### 3. تعديل بطاقة المنتج في `src/routes/category.$slug.tsx`
- لف الصورة بـ `<Link to="/product/$id" params={{ id: p.id }}>` لتفتح صفحة التفاصيل عند الضغط
- إضافة **السعر** كنص بارز تحت الاسم مباشرة (خارج الصورة)
- استبدال زر "اطلب هذا التصميم" بزر "عرض التفاصيل" (Link داخلي) — لأن خيارات الطلب الآن في صفحة التفاصيل
- الإبقاء على الـ hover effect

### 4. تسجيل المسار
سيُحدّث `src/routeTree.gen.ts` تلقائياً بواسطة TanStack Router.

### الملفات المتأثرة
- تعديل: `src/lib/products.ts`
- جديد: `src/routes/product.$id.tsx`
- تعديل: `src/routes/category.$slug.tsx`

### خارج النطاق
- لا سلة شراء ولا دفع — الطلب يبقى عبر واتساب
- باقي الأقسام (غير ستاندات المحابس) ما زالت بدون منتجات

**أرسل لي قائمة الأسعار والأوصاف القصيرة للمنتجات العشرة لأضمّنها مباشرة عند التنفيذ.**
